# HarmonyCam

Android app that turns your voice into live, natural-sounding vocal harmonies. You control them with your hands in front of the selfie camera, and the app records a video with glowing, audio-reactive visual effects. A lyrics prompter follows your singing; it is shown only on screen and is never recorded.

## Install

Every push to `main` builds a signed APK with GitHub Actions. Get it from:

- **Releases → latest → `HarmonyCam.apk`**, or
- **Actions → latest run → Artifacts → `HarmonyCam-apk`**

On the phone, open the APK and allow *Install unknown apps* when asked. Requires Android 10 or newer.

## Using it

1. Plug in your USB interface (e.g. Behringer U-PHORIA UM2) or headphones. Harmonies are only played back live on headphones or the interface, which prevents feedback.
2. Set the interface gain so the meter at the top-left peaks in amber, never red. Condenser mics need 48V phantom power on.
3. Tap **♪** to paste lyrics from the clipboard, then save. The prompter follows your voice. Tap it to go to the next line; hold it to go back.
4. Hit record. When you stop, the take is re-rendered at studio quality and saved to **Gallery → Movies/HarmonyCam**.

| Gesture | Effect |
|---|---|
| Voice hand (right side of screen): 1–4 raised fingers | number of harmony voices |
| Voice hand height | harmonies below ↔ around ↔ above your melody |
| Voice hand closed fist | mute harmonies |
| FX hand (left side): spread thumb and index | more reverb and stronger visuals |

Gestures can be turned off in Settings, which shows on-screen voice and height controls instead.

## How the sound is made

- **Live (headphones)**: full-duplex low-latency audio (Oboe/AAudio). Pitch is tracked with YIN and each note is snapped to the key (set it yourself, or let Auto detect it). Up to 4 harmony voices are generated by formant-preserving pitch shifting (Signalsmith Stretch), so they keep your vowel and timbre instead of sounding like chipmunks.
- **Natural feel**: each voice has its own small timing offset, slow pitch drift, slightly different timbre, level and stereo position. Harmonies follow your vibrato, and only your *sustained* tuning offset is corrected.
- **Final video**: the raw vocal and every gesture are recorded. After each take the harmonies are re-rendered offline with longer analysis windows and exact latency compensation, then polished with EQ, compression, plate reverb and a limiter. The result is encoded as 48 kHz / 320 kbps AAC alongside 1080×1920 H.264 video.

## USB interfaces (UM2 and similar)

- The app routes both mic and monitoring to the interface automatically. It reads only **Input 1** (the XLR/mic channel) by default; change this in Settings → Microphone.
- If your interface has a direct-monitor switch, turn it off so you hear only the harmonised mix.
- If the interface disconnects or the condenser mic is silent with phantom power on, the phone may not supply enough USB power. Use a powered USB-C OTG hub.

## Build locally

Use Android Studio (Ladybug or newer) and open this folder. The first build downloads the hand-tracking model and the offline English speech model into `app/src/main/assets` automatically.

The repo includes a side-load signing key (`app/harmonycam-sideload.jks`) so every build can update the previous install. Replace it with your own private key before publishing anywhere.
